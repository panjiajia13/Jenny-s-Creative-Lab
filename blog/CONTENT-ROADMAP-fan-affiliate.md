# 内容路线图 · 乐迷向 + Affiliate 变现（jenn.ghost.io）

方向已定：**服务乐迷(听众)**，用内容建流量，用 affiliate(联盟营销)变现。核心不是转去做音乐人服务，而是把"独立音乐推荐"这个主题做深、再自然接上"买装备"的钱。

## 变现漏斗逻辑（先看懂这个再看选题）
```
发现型内容（乐队/专辑推荐，信息型，好排名、引流量）
        │  内链导流
        ▼
装备型内容（唱机/耳机/黑胶，商业型，带 affiliate 链接 = 钱）
```
- **发现型** = 漏斗顶部：把乐迷吸进来、建品牌、攒内链权重。你现在两篇都属于这类。
- **装备型** = 漏斗底部：同一批乐迷"我想更好地听/收藏" → Amazon Associates 等联盟链接变现。
- 关键：**两类互相内链**（"用好唱机听这些专辑更过瘾 → 唱机指南"；反之装备文里推荐"配这些专辑听 → 乐队清单"）。

> ⚠️ 现实提醒：装备型大词（best turntables / best headphones）**KD 很高、被大站占据**，新站直接刚很难。所以**先用发现型内容把权威做起来**，装备型**从长尾切入**（best turntables under $200 for beginners 这种）。每个选题上线前，都用 SEMrush 查 KD，**新站只做 KD < 30 的**。

## Affiliate 起步（最简路径）
1. **注册 Amazon Associates**（唱机/耳机/黑胶最好接，门槛低）。
2. 每篇装备文顶部放 **FTC 合规免责声明**（"本文含联盟链接，通过链接购买我可能获得少量佣金，不额外增加你的花费"）——**必须有**，否则违规。
3. 装备文结构：一句话结论(推荐款) → 3–5 款对比(各配一句"为什么/适合谁") → 选购要点 → FAQ。**买家型内容要好扫读**。
4. 别一上来堆一堆装备文——**先 Ring 1，再逐步插 Ring 2**，保持站点"乐迷向"的主体认知。

## 内链地图（务必执行）
- 每篇 **Ring 1** → 链回 pillar(第一篇) + 1 篇相邻发现文。
- 每篇 **Ring 2** → 从相关 Ring 1 文里用锚文本导入（如"想升级听感？看我们的[唱机指南]"）。
- pillar(第一篇) → 逐步在正文自然位置链向 2–3 篇最重要的子文。

## 节奏与验证
- **每周 1–2 篇有深度的**，别追量。
- **每个选题上线前用 SEMrush 查 KD**，新站只做 **KD < 30 + 意图对 + Volume ≥ 100** 的。
- 每篇配一张**原创信息图**（像专辑时间线那样）→ 既提升体验，又是可嵌入外链诱饵。
